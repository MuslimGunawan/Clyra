## 🌌 Tentang Clyra

**Clyra** adalah platform web modern yang diciptakan sebagai pusat produktivitas serbaguna bagi developer, desainer, kreator konten, dan antusias teknologi. 

Alih-alih membuka banyak website terpisah yang penuh iklan dan pelacak untuk tugas harian (seperti kompresi gambar, format JSON, unduh media, atau buat QR code), **Clyra menggabungkan semuanya ke dalam satu tempat yang bersih, cepat, estetis, dan privat.**

## 🛠️ 1. Katalog Lengkap Utilitas (Tools Hub)

Clyra menyediakan 11 alat bantu esensial yang siap digunakan langsung dari browser Anda:

### 📥 1. Universal Media & Video Downloader
* Ekstrak dan simpan video dan audio dari berbagai platform sosial media.
* Mendukung **YouTube (Full HD 1080p & Audio MP3 320kbps)**, **Instagram Reel/Postingan**, dan **TikTok Tanpa Watermark**.
* Dilengkapi visual preview langsung dan indikator proses unduhan.

### 🗜️ 2. Image Compressor & Optimizer
* Kompres ukuran foto (JPG, PNG, WebP) dengan kontrol slider kualitas visual.
* Mengurangi ukuran file gambar secara signifikan untuk kebutuhan web tanpa merusak detail penting.
* Dilengkapi fitur perbandingan *Before vs After* interaktif.

### 🔄 3. Image Format Converter
* Konversi format gambar antar PNG, JPG, WebP, dan SVG dalam hitungan detik langsung di browser tanpa batas ukuran.

### 💻 4. JSON Formatter & TypeScript Generator
* Validasi sintaks JSON, perbaiki indentasi (Beautify/Minify), dan salin dalam satu klik.
* **Fitur PRO**: Otomatis membuat definisi interface TypeScript dari struktur JSON yang Anda masukkan.

### 🔒 5. Hash, Password & UUID Generator
* Generator password acak berkekuatan tinggi dengan perhitungan skor entropi kriptografis.
* Hashing teks instan menggunakan algoritma SHA-256, SHA-512, SHA-384, dan SHA-1.
* Generator UUID v4 unik untuk kebutuhan database dan identifier.

### 🎨 6. Color Studio & Palette Studio
* Color picker canggih dengan konversi instan nilai warna (HEX, RGB, HSL).
* Generator palet warna harmonis (Monochromatic, Analogous, Complementary, Triadic).
* Generator CSS Gradient studio siap salin untuk Tailwind CSS atau Vanilla CSS.

### 📝 7. Markdown Live Previewer & Editor
* Editor teks format markdown dengan live rendering preview HTML yang rapi.
* Dilengkapi template bawaan cepat: *README*, *Changelog*, dan *Technical Specification*.
* Menampilkan metrik kata, karakter, dan estimasi waktu baca (*read time*).

### ⚡ 8. SVG to React JSX Converter
* Ubah kode mentah SVG menjadi komponen React/Next.js (TSX/JSX) yang bersih dan siap di-import.
* Menyediakan output instan untuk *CSS Background Data URI*.

### 📱 9. Interactive QR Code Generator
* Buat QR code kustom untuk URL Website, Teks Bebas, Jaringan Wi-Fi, Email, dan Nomor Telepon.
* Kustomisasi warna background/foreground dan sematkan logo icon di tengah QR.

### 🔡 10. Text Case Converter
* Ubah format penulisan teks secara instan ke berbagai gaya: *UPPERCASE, lowercase, Title Case, camelCase, PascalCase, snake_case, kebab-case, CONSTANT_CASE*, dll.

### 📦 11. Base64 Codec
* Enkoder dan dekoder teks maupun file dokumen/gambar menjadi format string Base64 yang aman untuk transmisi data.

## 🧠 2. AI Prompt Vault (Galeri Prompt Siap Pakai)

Koleksi dan arsip perintah (*prompt engineering*) pilihan untuk berbagai model Artificial Intelligence ternama:

* **Model AI yang Didukung**: Midjourney v6, DALL-E 3, Stable Diffusion, Claude 3.5 Sonnet, ChatGPT.
* **Kategori Eksplorasi**: *3D & Render, Photography, Anime & Art, UI & Graphic Design, Coding & Logic, Creative Writing*.
* **Fitur Interaktif**:
  * Filter kategori dan pencarian keyword.
  * Modal detail lengkap dengan parameter aspect ratio, stylize, seed, dan negative prompt.
  * Tombol salin satu klik (*One-Click Copy Command*).
  * Formulir untuk menambah dan menyimpan prompt kreasi baru Anda sendiri.

## 💼 3. Web Projects Showcase (Etalase Portofolio)

Galeri etalase untuk memamerkan berbagai website, aplikasi web, dan projek karya yang telah dibangun:

* **Tampilan Visual Menarik**: Thumbnail berkualitas tinggi dengan overlay kategori dan tahun pembuatan.
* **Rincian Tech Stack**: Label teknologi yang digunakan (Next.js, TypeScript, Tailwind CSS, dll.).
* **Aksi Cepat**: Tautan langsung ke **Live Demo** dan **Source Code Repository**.
* **Filter Kategori**: Web App, Landing Page, Tool, Open Source, dan Client Project.

## ✨ Fitur & Kenyamanan Antarmuka Web

* ⌨️ **Command Palette (Ctrl + K / Cmd + K)**: Cari dan buka seluruh tool, halaman projek, atau navigasi website secara kilat hanya dengan keyboard.
* 🛡️ **Privat & Bebas Tracking**: Sebagian besar modul utilitas memproses data langsung di perangkat Anda tanpa menyimpan data ke server luar.
* 📱 **Desain Sepenuhnya Responsif**: Tampilan optimal di smartphone, tablet, laptop, hingga monitor resolusi tinggi.
* 🔔 **Interactive Toast Feedback**: Notifikasi visual halus setiap kali Anda menyalin teks, mengunduh file, atau memproses data.
